**Satisfies:** infrastructure de sécurité.

- [ ] **Given** un visiteur **When** il s'inscrit puis se connecte **Then** une session serveur est établie et l'identité est vérifiée côté serveur à chaque requête protégée
- [ ] **Given** une session révoquée ou expirée **When** une requête protégée arrive **Then** elle est refusée immédiatement, sans dépendre d'un cache client
- [ ] **Given** un utilisateur qui se connecte pour la première fois **When** son compte applicatif est créé **Then** l'opération est idempotente : deux connexions simultanées ne créent pas deux comptes
- [ ] **Deny :** une redirection après connexion vers une URL non présente dans la liste d'autorisation exacte est refusée
