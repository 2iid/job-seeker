**Satisfies:** infrastructure de sécurité — prérequis de toute clé d'API.

- [ ] **Given** une variable requise absente ou mal formée **When** l'application ou le worker démarre **Then** le démarrage échoue immédiatement avec le nom de la variable fautive — jamais un échec silencieux à la première requête
- [ ] **Given** un secret serveur **When** on inspecte le bundle client **Then** il n'y figure pas ; seules les variables explicitement publiques sont exposées
- [ ] **Given** un journal ou un rapport d'erreur **When** une variable sensible y apparaîtrait **Then** elle est masquée
- [ ] **Deny :** aucune valeur par défaut n'est fournie pour un secret — une variable manquante est une erreur, pas un `""`
