# =============================================================================
#  distribution.txt — the single inventory of what an adopter receives.
#
#  This file exists because the installer used to carry its own hardcoded list,
#  and that list drifted: `evidence.yml` shipped as a feature in v3.13.0 and was
#  never added, so for two versions every adopter's PR evidence gate silently did
#  not exist. `vendor/`, `THIRD_PARTY_NOTICES.md`, `docs/engineering/` and the
#  eval suite were missing the same way.
#
#  One list, read by:
#    · scripts/adopt/install.sh   — what to copy
#    · scripts/adopt/upgrade.sh   — what it owns
#    · scripts/test/test-install-safety.sh — asserts every line arrives
#
#  Adding a capability without adding it here now fails a test rather than
#  quietly not shipping.
#
#  Syntax: one path per line, relative to the kit root. A directory copies
#  recursively. `?` prefix = optional (absent from a trimmed checkout is fine).
# =============================================================================
